# 机械臂连接协议文档

## 1. 概述

本项目通过 **Modbus TCP** 协议与五轴机械臂进行通信。机械臂控制器作为 Modbus TCP Server，上位机作为 Modbus TCP Client，通过标准的 Modbus 读写操作实现对机械臂的控制与状态监测。

支持的五个轴为：**X轴、Y轴、Z轴、A轴（旋转轴）、B轴（旋转轴）**。

---

## 2. 通信连接参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 协议 | Modbus TCP | 基于 TCP/IP 的 Modbus 通信 |
| IP 地址 | `192.168.0.1` | 机械臂控制器 IP |
| 端口 | `502` | 标准 Modbus TCP 端口 |
| 从站 ID (Slave ID) | `1` | 固定为 01 |
| 响应超时 | 5 秒 | 读写操作的等待超时时间 |

> 可通过配置文件 `config.json` 或环境变量覆盖默认参数（详见第 9 节）。

## 3. 数据编码规则

### 3.1 32 位有符号整数编码

所有位置、速度数据均采用 **32 位有符号整数（int32_t）**，存储在两个连续的 **16 位 Modbus 保持寄存器（Holding Register）** 中。

**字节序（Byte Order）：**

```
寄存器 N     (低 16 位) — Low Word
寄存器 N+1   (高 16 位) — High Word

32 位值 = (High Word << 16) | Low Word
```

**编码示例：**

```cpp
// 16 位寄存器 → 32 位整数
uint32_t combined = (static_cast<uint32_t>(reg_high) << 16) | static_cast<uint32_t>(reg_low);
int32_t value = static_cast<int32_t>(combined);

// 32 位整数 → 16 位寄存器
low  = static_cast<int16_t>(value & 0xFFFF);
high = static_cast<int16_t>((value >> 16) & 0xFFFF);
```

> **注意：** 位置值原始读取，无需缩放因子，直接以脉冲数/编码器计数表示。

## 4. 轴配置

### 4.1 轴定义

| 轴 ID | 名称 | 物理描述 | 安全限位（默认） |
|-------|------|---------|-----------------|
| 0 | X 轴 | 水平前后移动 | -1,000,000 ~ 1,000,000 |
| 1 | Y 轴 | 水平左右移动 | -1,000,000 ~ 1,000,000 |
| 2 | Z 轴 | 垂直上下移动 | -1,000,000 ~ 1,000,000 |
| 3 | A 轴 | 旋转轴 | -180,000 ~ 180,000 |
| 4 | B 轴 | 旋转轴 | -180,000 ~ 180,000 |

> 单位：脉冲数（Pulse），无物理单位换算。

### 4.2 寄存器地址映射

每个轴占用 **7 个寄存器地址**，连续分布，轴间间隔 10 个地址。

| 寄存器类型 | 偏移规律 | 说明 |
|-----------|---------|------|
| 目标位置寄存器 | 基址 + 0 | 写入目标位置（2 个寄存器） |
| 当前位置寄存器 | 基址 + 2 | 读取当前位置（2 个寄存器） |
| 速度寄存器 | 基址 + 4 | 读写运行速度（2 个寄存器） |

**线圈（Coil/Relay）地址：**

| 线圈类型 | 偏移规律 | 说明 |
|---------|---------|------|
| 正转继电器 | 基址 + 2 | 控制轴正向连续运动 |
| 反转继电器 | 基址 + 3 | 控制轴反向连续运动 |
| 绝对定位继电器 | 基址 + 4 | 触发绝对定位运动 |
| 相对定位继电器 | 基址 + 5 | 触发相对定位运动 |

### 4.3 各轴完整地址表

| 轴 | 目标位置寄存器 | 当前位置寄存器 | 速度寄存器 | 正转继电器 | 反转继电器 | 绝对定位继电器 | 相对定位继电器 |
|---|:-------------:|:-------------:|:---------:|:---------:|:---------:|:-------------:|:-------------:|
| X 轴 (0) | 7800 | 7802 | 7804 | 7502 | 7503 | 7504 | 7505 |
| Y 轴 (1) | 7810 | 7812 | 7814 | 7512 | 7513 | 7514 | 7515 |
| Z 轴 (2) | 7820 | 7822 | 7824 | 7522 | 7523 | 7524 | 7525 |
| A 轴 (3) | 7830 | 7832 | 7834 | 7532 | 7533 | 7534 | 7535 |
| B 轴 (4) | 7840 | 7842 | 7844 | 7542 | 7543 | 7544 | 7545 |

## 5. Modbus 功能码

| 操作 | Modbus 功能码 | 说明 |
|------|-------------|------|
| 读保持寄存器 | `0x03` | 读取位置、速度数据 |
| 写单个寄存器 | `0x06` | 写单个 16 位寄存器 |
| 写多个寄存器 | `0x10` | 写连续多个 16 位寄存器 |
| 读线圈 | `0x01` | 读取继电器状态 |
| 写单个线圈 | `0x05` | 控制继电器通断 |

## 6. 通信接口说明

### 6.1 连接管理

```
connect(ip, port)      → 连接机械臂 Modbus TCP Server
disconnect()           → 断开连接
isConnected()          → 查询连接状态
```

连接流程：
1. 创建 `modbus_new_tcp(ip, port)` 上下文
2. 设置从站 ID 为 1
3. 设置响应超时 5 秒
4. 调用 `modbus_connect()` 建立连接
5. 读取寄存器 7802 验证连接有效性
6. 读取各轴初始位置

### 6.2 位置控制

#### 6.2.1 绝对定位（moveToPosition）

```
moveToPosition(axis_id, target_position) → bool
```

执行流程：
1. 停止该轴的正转和反转继电器
2. 延时 100ms
3. 将目标位置（32 位整数拆分为两个 16 位值）写入目标位置寄存器
4. 清除绝对定位继电器状态
5. 置位绝对定位继电器，触发运动
6. 延时 100ms 等待指令生效

#### 6.2.2 连续运动（startContinuousMovement）

```
startContinuousMovement(axis_id, direction) → bool
```

参数 `direction`：`true`=正转，`false`=反转

执行流程：
1. 清除绝对定位继电器
2. 关闭反方向继电器
3. 延时 50ms
4. 置位目标方向继电器

#### 6.2.3 停止运动

```
stopContinuousMovement(axis_id)    → bool   // 停止指定轴连续运动
stopAllMovements(axis_id)          → bool   // 停止指定轴所有运动
```

### 6.3 位置读取

```
readPosition(axis_id) → double   // 读取指定轴当前位置
readSpeed(axis_id)    → int32_t  // 读取指定轴当前速度
```

读取流程：
1. 从当前位置寄存器连续读取 2 个 16 位寄存器
2. 按 `(High << 16) | Low` 组合为 32 位有符号整数
3. 直接返回原始值（无缩放）

### 6.4 速度设置

```
setSpeed(axis_id, speed) → bool   // 设置指定轴速度
```

默认速度值为 `70000`，连接成功后自动对所有轴设置此速度。

### 6.5 自动轮询

```
startAutoRead(interval = 0.5f)    → 启动定时轮询（默认 0.5 秒间隔）
stopAutoRead()                     → 停止定时轮询
```

定时轮询所有 5 个轴的当前位置，并通过回调函数通知状态更新。

### 6.6 状态回调

```cpp
setStatusCallback(function(const ArmStatus&))
```

`ArmStatus` 结构包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `current_positions` | `vector<int32_t>` | 5 个轴的当前位置 |
| `target_positions` | `vector<int32_t>` | 5 个轴的目标位置 |
| `connected` | `bool` | 连接状态 |
| `status_message` | `string` | 状态描述信息 |

## 7. S 型路径规划协议

### 7.1 概述

S 型运动控制器（`SMovementController`）基于 Modbus 控制器上层，实现球冠表面的网格扫描路径规划，用于图像采集与拼接。

### 7.2 球冠参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 球冠半径 (R) | 230000 | 球冠的半径（脉冲数） |
| 球冠高度 (h) | 50000 | 球冠的高度（脉冲数） |
| 高度偏移 (dH) | 0 | Z 方向附加偏移 |
| Z 基准高度 | 80000 | Z 轴基准高度 |
| 步进间隔 | 10000 | 网格点之间的步进距离 |
| 运动速度 | 70000 | 各轴运动速度 |

### 7.3 网格路径生成

在矩形区域内按指定行列数生成 S 型扫描路径，逐行往返：

```
行 0: 起点 → 终点 (从左到右)
行 1: 终点 → 起点 (从右到左)
行 2: 起点 → 终点 (从左到右)
...
```

每个路径点包含：`(x, y, z, a, b)` 以及所在网格的行列索引 `(row, col)`。

### 7.4 运动流程

1. **初始化**：根据网格尺寸、起点、终点和步进生成路径点列表
2. **逐个移动到路径点**：依次发送各轴绝对定位命令（X → Y → Z → A → B）
3. **到位等待**：等待 200ms 确保机械臂到达目标位置
4. **图像采集**：到达每个位置后触发相机拍照
5. **图像保存**：按行、列索引命名并保存图像
6. **继续下一位置**：直到所有路径点执行完毕

## 12. 注意事项

1. **线程安全**：所有 Modbus 读写操作通过 `std::mutex` 互斥锁保护，避免多线程并发访问冲突。
2. **连接状态**：每次 Modbus 操作前检查 `connected_` 标志和 `modbus_` 上下文的有效性。
3. **断线重连**：实现连续失败计数（最大 5 次），超过阈值后自动尝试重连（最多 10 次）。
4. **安全限位**：A 轴和 B 轴默认限位为 ±180,000，防止旋转超出机械范围。
5. **超时设置**：响应超时设为 5 秒，适应工业现场网络延迟。
6. **调试模式**：可通过 `modbus_debug` 配置开启 Modbus 通信日志，便于排查通信问题。
