# 安全说明 (Security Notes)

## 通信安全

### Modbus TCP (机械臂)

- 协议: Modbus TCP，端口 502，明文传输，无加密 / 无鉴权
- 安全假设: 运行在**隔离的局域网**中，仅可信设备可访问机械臂网段
- 风险: 任何能访问该网段的设备可读取/写入寄存器，直接控制 5 轴运动
- 缓解:
  - 机械臂应部署在独立 VLAN
  - 控制 PC 的防火墙应限制 502 端口的入站连接
  - 软件连接前提示用户确认物理安全

### ToupCam (相机)

- 协议: 厂商私有 SDK，USB / 网络连接
- 安全假设: 物理连接，无远程攻击面

### 配置文件

- `config.json` 明文存储 IP 地址和端口，位于可执行文件同目录
- 风险: 目录权限决定谁可读取配置
- 日志中不暴露 IP 地址（spdlog 仅记录连接状态，不记录 IP）

## 运行时安全

### 机械臂运动

- 紧急停止按钮 (EMERGENCY STOP) 位于侧边栏和顶部工具栏，点击后停止所有 5 轴运动
- 软件层限位: `ConfigManager::axisMinPos/axisMaxPos` 定义每轴安全行程
- 硬件层限位: 机械臂固件的软限位 + 机械限位开关（硬件保护）

### 数据存储

- 扫描图像保存在用户指定的工作目录（默认 `Documents/ScannerData`）
- 检测结果 JSON + PDF 报告同目录保存
- 日志文件 (`armsightstitch.log`) 滚动覆盖，旧日志不保留

## 已知限制

- 无用户认证系统（桌面单机软件，假设操作系统用户认证已足够）
- 无审计日志（spdlog 仅记录技术调试信息，非审计用途）
- 无远程升级机制（软件升级需手动替换可执行文件）
