# 项目功能逻辑

ArmSightStitch 是面向明场显微镜的自动扫描与缺陷检测上位机软件，基于 Qt 构建图形界面，通过 Modbus TCP 协议控制五轴机械臂携带样品在物镜下方逐点移动并采集图像，最终将各局部视场拼接为完整的大幅面样品图，同时支持对拼接结果进行表面缺陷检测。

## 模块架构

整个系统由一个中央控制器 AppController 持有五个功能模块的实例，通过抽象接口将它们注入 MainWindow 和 WorkflowManager。各模块之间不存在编译期依赖，具体实现类在运行时通过工厂或直接构造注入，这种设计使各模块可以独立测试和替换。

机械臂通信模块封装 Modbus TCP 协议，提供两个层面的接口：低层面的单轴读写（寄存器、线圈），以及高层面封装好的并发运动命令（X/Y 两轴并发、X/Y/Z 三轴并发）。模块内部维护一个后台自动轮询线程，在非扫描期间周期性地读取各轴当前位置和设定速度，供 UI 上各轴的实时数值显示和进度条。扫描期间该自动轮询暂停，以避免与运动的命令序列竞争 Modbus 连接的互斥锁。模块内置五轴软限位校验，所有移动指令在发送前强制检查目标位置是否越界。

相机模块封装相机的 SDK，支持设备枚举、连接、开始/停止采集、触发式单帧捕获、曝光/增益调节、旋转/翻转和负片模式。采集模式采用"数据回调 + 触发式读取"：SDK 每产生一帧新图像调用回调，回调将帧深拷贝到内部缓存；扫描时运动线程调用触发式接口从缓存中克隆当前帧，不阻塞数据流。触发式捕获与视频流独立，避免帧缓存互斥锁的竞争。相机预览帧通过信号槽持续推送到 UI 线程显示在左侧面板的 QLabel 中。

检测模块提供两套可切换的算法，共用一个 IDetector 接口。YOLO 检测器基于 ncnn 框架加载 YOLOv5 模型，支持 GPU 加速，可区分裂缝、划痕和凹坑三种缺陷类型并输出置信度，输入尺寸固定为 640×640，经置信度阈值和 NMS 过滤后返回结果。Dust 灰尘检测器基于传统图像处理，通过 CLAHE 对比度增强、高斯模糊背景估计、背景减除和 Otsu 自适应阈值提取暗斑颗粒，再用形态学开闭运算去噪和连通域面积过滤，随后将被检出区域用背景估计填充后进入下一轮迭代，直到达最大迭代次数或检不出新颗粒为止。两套算法均输出统一格式的 Detection 结构体，包含包围框、中心点坐标、类别和置信度。

拼接模块提供三种拼接算法可选：网格拼接（按行列位置直接拼接）、特征拼接（基于特征点匹配，内部保留但 UI 暂不暴露）和基于缩放图的网格拼接（根据每个单元格的缩放因子调整尺寸后再拼接）。模块支持按文件名中的行列下标解析图像位置，也兼容传统的按目录文件名的自然排序。拼接的进度和状态通过回调推送到 UI 线程显示在进度条中。拼接支持中心裁剪（裁去每帧边缘重叠区域）和接缝羽化。

## 自动扫描工作流

工作流管理模块是一个有限状态机，管理从连接设备到拼接完成的六阶段全自动流程。状态按顺序流转：空闲 → 连接机械臂 → 连接相机 → 归零 → 扫描 → 拼接 → 空闲。每个状态转换由一个单次 QTimer 触发，前一步成功则调度下一步，失败则转入错误状态并发出错误信号。

连接机械臂阶段通过配置中的 IP 和端口号与机械臂建立 Modbus TCP 连接，成功后为 X/Y/Z 三轴设置默认速度。连接相机阶段枚举设备列表，连接第一个可用相机并开启连续采集。归零阶段通过三轴并发移动将 X/Y/Z 复位至零点，随后通过轮询确认三轴均已到达（超时 10 秒，容差从配置读取），确认到达后计算扫描区域的物理终点坐标并启动扫描。扫描阶段由路径规划与运动控制模块承载，在下文单独展开。扫描完成后，通过状态回调中的 "completed" 字符串检测正常结束，触发拼接阶段。拼接阶段从扫描运行目录加载图像文件，按文件名中的行列下标解析网格位置并执行拼接，拼接结果通过信号槽派发到 UI 线程显示在右侧面板中。

## 扫描路径与运动控制

扫描路径在启动时同步完成计算，生成一个包含全部网格点坐标的向量，运动线程后续只按索引遍历。网格由四个参数定义：起点 XY、终点 XY、列数和行数，步长由起止范围和网格数相除得出。遍历顺序采用 S 形之字形排列：偶数行从左到右，奇数行从右到左，这种排法将总行程从逐行单向的约 2NM 步减少到约 NM+(N-1) 步。生成路径的同时为每个点附加行列元数据，供后续图像命名和拼接定位使用。

对于曲面样品，系统采用球冠模型进行 Z 轴高度补偿：将样品曲面近似为球面的一部分，计算每个扫描点到球冠中心的水平距离 r，由球冠投影半径 R 和球冠高度 h_cap 反推球体半径 Rs，再利用球体方程计算该点在球面上的高度 cap，最终 Z = zBase − cap − dH。r 超出 R 的区域 Z 保持 zBase 不变。当球冠高度为零时补偿算法自动旁路，Z 轴模式也可切换为手动模式：从 JSON 文件中读取每个网格位置的自定义 Z 值，覆盖球冠补偿的计算结果。

运动线程的主循环对每个网格点执行四步：移动 → 稳定等待 → 采集 → 保存入队。移动步骤采用三轴并发启停策略：在同一 Modbus 命令序列中写入 X/Y/Z 三轴目标位置，按固定时序触发绝对定位继电器——轴间触发间隔是为了电气层面避免继电器同时吸合造成浪涌——写入完成后释放 Modbus 互斥锁进入等待阶段。等待阶段独立轮询各轴当前位置，单次轮询间隔 20ms，超时上限 300 次。确认到达采用连续两次读取均达标的方式，单次确认不可靠是因为通信干扰可能产生瞬时跳变。稳定等待按配置的 dwell 时长执行，期间每 5ms 检查一次暂停标志。采集步骤调用相机的触发式接口从帧缓存克隆当前帧，最多重试三次。采集成功后帧数据连同行列元数据封装为一个任务推入线程安全队列，通过条件变量唤醒后台保存线程，运动线程随即处理下一个网格点，不等待写盘完成。

后台保存线程在运动线程启动时一并创建，从队列取任务后通过回调将图像写入磁盘，文件命名格式为目录/行_列_Z.png。除原始图像外，保存线程还同步生成负片图像（255 减原始像素值）和一个缩略图副本，负片和缩略图数据通过互斥锁保护的共享 map 推送给 UI 线程的每个单元格 QLabel。生产和消费两端通过队列和条件变量协作，当运动线程完成所有网格点后设置运行标志并唤醒消费者，消费者检测到退出信号后退出循环，运动线程通过 join 等待消费者完全退出，保证函数返回前所有图像已写入磁盘。

暂停和终止通过三个原子布尔标志 running_、paused_ 和 stop_requested_ 驱动。暂停检测在 dwell 等待期间、dwell 完成后和采集完成后执行，被暂停时线程进入睡眠-检查循环（每 50ms 一次）。终止检查覆盖循环入口、移动完成后、dwell 期间和采集完成后。

## 图像拼接

拼接模块支持三种拼接算法：网格拼接直接将图像按行列位置放置到画布上，适用于采集位置精度足够的场景，并通过中心裁剪裁去每帧边缘区域避免重叠黑边；特征拼接通过 ORB 或 SIFT 特征匹配计算相邻帧之间的位移再拼接，对位置漂移有更高容忍度，但同时需要更多的计算资源和时间；缩放图拼接先读取每个单元格的缩放因子 JSON 文件，用因子调整每帧图像大小后再做网格拼接，适用于样品表面存在局部缩放差异的场景，缩放因子可通过单元格右键手动设定。

拼接过程支持接缝羽化处理，在相邻帧的重叠区域做加权渐变混合以避免硬边拼接缝。拼接结果通过信号槽派发到 UI 线程，以 QPixmap 形式显示在右侧可缩放滚动的显示区域。同时系统检测扫描目录下是否存在负片子文件夹，若存在则自动执行负片拼接并在 UI 中提供负片切换按钮以对比显示正片和负片的拼接结果。

## 表面缺陷检测

检测模块执行后返回一组 Detection 结构体，每个结构体包含目标在原始图像坐标系下的矩形包围框、中心点坐标、类别名称和置信度。YOLO 检测器的类别为裂缝、划痕和凹坑，置信度为模型输出的目标置信度乘以类别概率。Dust 灰尘检测器的类别统一为 dust，置信度基于面积映射到 [0, 1] 区间（面积越大置信度越高）。去重阶段对所有检出框按面积降序排列，用基于较小框面积的 IoU 做贪心合并，合并时累加实际像素面积避免同一颗粒被多次计数。

检测结果以两种形式导出：JSON 文件记录每个检出目标的 id、类型、类别编号、置信度、包围框坐标、中心点坐标和面积；标注图像在原始图或拼接图上绘制检测框，YOLO 结果用绿色框标注，灰尘结果用红色框标注，框上方标注类别名和置信度数值。拼接并检测完成后，用户还可以载入其他图像（例如局部瑕疵修复后的二次验证图），软件按照统一命名规则自动识别该位置的网格坐标，并将检测结果叠加到拼接图中展示。

两套算法的参数通过检测设置对话框调节，参数值在确认后写入算法实例，在下一次检测调用时生效。对话框内可选择算法类型并加载单张图片执行检测，检测结果覆盖在原图上并保存到图片同目录。

## 线程模型与 UI 布局

整个系统共运行五条线程：UI 主线程处理 Qt 事件循环和用户交互；运动线程执行路径遍历和 Modbus 命令发送；保存消费者线程处理磁盘 I/O 和缩略图生成；AutoRead 线程在非扫描期间周期性轮询机械臂位置和速度；相机 SDK 线程由相机 SDK 内部管理，负责帧数据产生和回调。线程间所有共享数据均受互斥锁保护——扫描目录字符串、网格缩略图 map、Modbus 连接锁、帧缓存锁和各模块状态结构体均有各自的互斥锁，锁的职责单一明确。

UI 布局采用左右分栏设计。左侧为硬件控制面板，从上到下依次为：相机连接区域含枚举按钮、连接/断开按钮、拍照按钮和实时预览画面，预览画面下方是曝光和增益滑块与相机的旋转/翻转/负片等模式开关；机械臂连接区域含 IP 端口输入、连接/断开按钮、X/Y/Z 三轴的 JOG 手动位移按钮组、三轴当前位置数值显示、速度设置旋钮、坐标数值和软限位。右侧主工作区从上到下依次为：顶部快捷工具栏包含执行扫描、暂停、继续、停止按钮和算法选择与参数配置下拉菜单；中部是一个表格控件，每个单元格对应网格中的一个扫描位置，单元格内显示该位置的缩略图，右键菜单提供设置该位置 Z 值、设置缩放比例和替换当前帧三个操作，左键点击则打开全屏预览窗口；下部是两个标签页切换区域，分别在拼接结果显示和检测结果显示之间切换，均支持缩放滚动和负片切换；底部是状态日志面板和状态栏，状态日志面板输出时间戳日志、错误计数和清空按钮，状态栏显示机械臂连接状态、机械臂位置和速度、相机分辨率和帧率以及当前扫描操作状态。

## 配置管理

所有运行参数通过 JSON 配置文件或环境变量设定，环境变量优先级更高。配置分为以下几组：机械臂通信配置包括 IP 地址、端口号和默认运动速度；相机配置包括初始分辨率、曝光时间和增益；网格扫描配置包括列数和行数、步长、基准 Z 平面高度、每点稳定等待时间和图像保存基础路径；球冠补偿配置包括投影半径、球冠高度、固定偏移量和 Z 轴模式选择；拼接配置包括中心裁剪尺寸、算法选择和接缝羽化宽度；检测算法配置包括算法类型选择（YOLO 或 Dust）、NMS 和置信度阈值以及所有传统检测算法的流水线参数（CLAHE 强度、背景模糊核大小、最小/最大颗粒面积、膨胀次数、最大迭代次数和 NMS 合并 IoU）；还有五轴各自的最小/最大软限位值和位置到达容差。配置管理器在程序启动时读取默认值，加载配置文件，再应用系统环境变量覆盖。
