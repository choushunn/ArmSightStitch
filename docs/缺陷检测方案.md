# 缺陷检测方案

> ArmSightStitch 表面污染物标识与缺陷分析方案

项目通过两套算法实现表面缺陷检测，在运行时切换使用。YOLO 检测器将图像缩放至 640×640 后送入 ncnn 推理引擎。输出为每个检测框的坐标、置信度和类别概率，置信度经阈值过滤后用非极大值抑制去除重叠框，最终保留的检测框带三类标签——裂缝、划痕和凹坑。推理在 Vulkan 可用时走 GPU，否则走 CPU。

Dust 检测器处理流程分为六步。第一步将输入图像转灰度后做 CLAHE 对比度增强。第二步用大高斯核对灰度图做模糊，以模糊结果作为背景估计，原图减背景得到残差图，取负值部分作为暗斑候选。第三步对暗斑候选图做 Otsu 自适应二值化，得到初步二值图，然后用形态学开运算去除孤立噪点（3×3 椭圆核，迭代两次）、闭运算填补空洞（3×3 椭圆核，迭代一次）。第四步对二值图做连通域分析，丢弃面积小于 minArea 的连通域。第五步将保留下来的连通域在原始灰度图上用背景估计值填充，并对填充边界做高斯模糊过渡。第六步对填充后的灰度图重复以上步骤，最多迭代 maxIter 轮，或某轮迭代后无新增像素则提前停止。所有轮次的检出区域合并到同一张二值 mask 中。

合并后的 mask 再做一次连通域分析，丢弃面积大于等于 maxArea 的连通域。若 nmsIou 阈值大于零，对保留下来的检测框做贪心合并——按面积降序排列，对 IoU（分母取两框中较小框的面积）超过阈值的框，合并为两者的包围框并累加像素面积。

每个检出目标的属性由检测算法不同而不同。YOLO 检测器返回包围框坐标、类别 ID、类别名称和置信度。Dust 检测器返回包围框坐标和类别名称固定为 dust；置信度由面积映射得到，当 maxArea 大于零时等于 area 除以 maxArea，当 maxArea 为零时恒为 1.0。

检测结果导出为 JSON 文件，保存到扫描运行目录。每一条记录包含 id、type、class_id、confidence，以及 bbox（x, y, width, height）、center（x, y）和 area。同时生成标注图像，YOLO 结果用绿色框标注并附带类别标签和置信度，Dust 结果用红色框标注并在左上角标注颗粒总数。

两套算法的参数通过检测设置对话框调节，参数值在确认后写入算法实例，在下一次检测调用时生效。对话框内可选择算法类型并加载单张图片执行检测，检测结果覆盖在原图上并保存到图片同目录。
