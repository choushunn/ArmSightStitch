# ArmSightStitch - 工业风侧边栏UI设计规范

## 一、设计理念

### 1.1 核心原则
| 原则 | 说明 |
|------|------|
| 功能暴露 | 结构清晰，每个功能区域有明显视觉边界 |
| 材质诚实 | 深色金属基调，不做无意义的装饰 |
| 状态可读 | 连接/运行/错误状态通过颜色即时识别 |
| 操作高效 | 高密度布局，常用控件始终可见 |

### 1.2 工业风特征
- 深色钢质底板 `#16191D` + 面板层级叠加
- 最小圆角 (2px)，接近直角的机械感
- 左侧彩色指示条用于功能菜单选中态
- 等宽字体用于数值/日志，模拟工业终端
- 按钮按下态用 border-width 变化模拟机械按压

### 2.1 背景色阶（从深到浅）

| 色值 | 名称 | 用途 |
|------|------|------|
| `#16191D` | 底板色 | 主窗口背景、日志面板、表格底色 |
| `#1C1F24` | 面板色 | 侧边栏、分组框、工具栏、菜单栏 |
| `#23262C` | 控件色 | 按钮、输入框、下拉框默认背景 |
| `#2A2D34` | 悬浮色 | Hover 状态背景 |
| `#32353D` | 边框色 | 所有控件边框、分隔线 |

### 2.2 功能色

| 色值 | 名称 | 用途 |
|------|------|------|
| `#E07B3A` | 工业橙 | 强调色、菜单选中条、分组框标题 |
| `#4A90D9` | 工业蓝 | 主操作按钮、Focus 边框、进度条 |
| `#3CB371` | 工业绿 | 已连接状态、运行成功 |
| `#D9534F` | 工业红 | 断开连接、错误、停止按钮底色 |
| `#F5A623` | 安全黄 | 暂停/等待状态 |

### 2.3 文字色

| 色值 | 用途 |
|------|------|
| `#D4D6D9` | 主文字（标题、按钮文本、选中项） |
| `#8B8E94` | 次要文字（标签、未选中菜单、placeholder） |
| `#5A5D63` | 禁用文字 |

### 2.4 配色原则
> "深底色 + 高对比强调" -- 底板最深，逐层提亮，功能色低饱和度不刺眼

## 四、间距系统

### 4.1 基准网格
- 基准单位: **8px** (工业模数)
- 微间距: `4px` (紧密元素间)
- 标准间距: `8px` (控件内 padding)
- 组间距: `12-16px` (分组框内 padding)

### 4.2 具体规格

| 位置 | 间距值 | 说明 |
|------|--------|------|
| 侧边栏内边距 | `6px` | hwSectionLayout margins |
| 扫描面板内边距 | `12px` | armPosPanelLayout margins |
| 分组框内边距 | `8px` | QGroupBox padding |
| 按钮内边距 | `4px 8px` | compact button; `6px 14px` action button |
| 菜单按钮内边距 | `12px 16px` | 宽大操作区 |
| 菜单按钮间距 | `0px` | 紧密堆叠（通过边框区分） |
| 分隔线上下 | 无额外 margin | 紧贴上下元素 |
| 日志面板内边距 | `6px` | QTextEdit padding |

## 五、侧边栏功能分区逻辑

```
+====================================+
|  ZONE 1: 硬件连接区 (always shown)  |
|  ┌──────────────────────────────┐  |
|  │ 相机: [Combo] [搜][连][拍]    │  |
|  │ [x] 实时检测                  │  |
|  │ 机械臂: ● IP_____ Port____ [连]│  |
|  └──────────────────────────────┘  |
+------------------------------------+  <- 2px 分隔线 #32353D
|  ZONE 2: 功能菜单 (互斥三选一)      |
|  ▊ 扫描  (选中: 左侧3px橙条)       |
|  ▊ 拼接                           |
|  ▊ 检测                           |
+------------------------------------+
|  ZONE 3: 展开面板 (仅扫描时可见)    |
|  ┌ 位置控制 ──────────────────┐   |
|  │ X [Spin] Y [Spin]          │   |
|  │ Z [Spin] [移动][读取][归零] │   |
|  └────────────────────────────┘   |
|  ┌ S型扫描 ──────────────────┐   |
|  │ [  开始  ] [  暂停  ]      │   |
|  └────────────────────────────┘   |
+------------------------------------+
|  ZONE 4: 弹性空间 (spacer)          |
+------------------------------------+
|  ZONE 5: 日志面板 (bottom fixed)    |
|  ┌──────────────────────────────┐  |
|  │ [INF] System ready...        │  |
|  │ [WRN] No camera detected...  │  |
|  └──────────────────────────────┘  |
+====================================+
```

### 分区设计理由
1. **硬件连接区始终可见** -- 连接状态是操作前提，必须一眼确认
2. **菜单按钮互斥** -- 一次只进行一种工作模式，降低认知负荷
3. **展开面板按需显示** -- 减少非活动模式的视觉噪音
4. **日志底部固定** -- log 面板锚定底部，其余区域弹性填充

## 六、按钮样式规范

### 6.1 分类体系

| 类别 | 应用按钮 | 高度 | 颜色策略 |

## 八、布局优化建议

### 8.1 当前布局问题
1. **hwSection 内边距过大** -- 当前 `6px`，在窄面板中占用过多空间
2. **armPosPanel 左右内边距 12px** -- 可保持，给内容呼吸空间
3. **分组框内控件间距 4px** -- 合理，密集但不拥挤
4. **menuSeparator 使用 QFrame::Sunken** -- 改为纯色线更工业

### 8.2 优化方向
1. 侧边栏默认宽度建议 `260px`，最小 `220px`
2. `hwSection` 的 `spacing` 从 `2px` 改为 `4px`，增加相机区和机械臂区的呼吸感
3. `armConnLayout` 水平间距从 `2px` 改为 `4px`
4. 移除 `QGroupBox` 上现有的内联 styleSheet（会被 QSS 覆盖，避免冲突）
5. 图片预览区 `QLabel` 的内联 styleSheet 同样可移除

### 8.3 代码改动建议
- `main.cpp` 启动时加载 `industrial_theme.qss`
- `MainWindow.cpp` 中通过 `setProperty` 或 `setStyleSheet` 动态切换按钮文字颜色状态
- `appendLog()` 中日志颜色使用 QSS 一致的色值
